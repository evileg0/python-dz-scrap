Проект для скрейпинга цен инструментов в составе индекса IMOEX с сайта smartlab

Создание новой БД (используется локальный движок sqlite3 moex_db.db)

- Запустить db.py

Добавление задачи скрейпинга в Prefect

- Запустить pref_sc.py

Генерация файлов с графиками для каждого тикера

 - Запустить plot_pics.py

Файлы с графиками изменения цен можно посметреть в папке pics


Используемые библиотеки:

matplotlib==3.10.1

pandas==2.2.3

prefect==3.2.14

selenium==4.29.0

webdriver-manager==4.0.2
